# ProfitLands

ProfitLands is a browser-based financial strategy game prototype.

## V1
- Start with $1,000
- Four timed modes: Fast, Standard, Long, Persistent
- Limited actions each day
- Fictional stock market
- Businesses and property
- Daily income
- Random market/news events
- Local browser save
- Responsive interface

## Modes
- Fast: 5-minute days, 4 actions
- Standard: 15-minute days, 6 actions
- Long: 1-hour days, 10 actions
- Persistent: 24-hour days, 12 actions

This first version is intentionally a client-side prototype. Multiplayer, accounts, persistent online worlds, player trading, loans, alliances, defense, and sabotage can be added in later versions.
